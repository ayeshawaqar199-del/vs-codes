SmartHire: AI-Assisted Job Matching

Bridging the gap between employers and top-tier candidates using Python (Django), spaCy, Sentence Transformers, and PostgreSQL vector similarity.

Hybrid NLP Matching

Combines keyword extraction via spaCy with deep contextual semantic embeddings using Sentence Transformers (50/20/10/20 weight formula).

PostgreSQL Backend

Reliable relational database management for candidate profiles, parsed resumes, job specifications, and real-time application tracking.

Real-Time Job Stream

Live job feeds updating instantly with relative timestamps, verified salary indicators, and instant AI compatibility scores.
